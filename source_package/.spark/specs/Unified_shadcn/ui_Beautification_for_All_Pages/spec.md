# 需求分析
## 需求描述
- 全局UI风格统一：统一系统所有页面的视觉表现，消除不同页面组件样式不一致问题
  - 所有页面的卡片、指标卡、按钮、表单、表格、弹窗等组件样式完全统一，符合设计规范
- 指标卡组件统一：将不同页面的指标卡样式统一为规范样式
  - 所有统计类指标卡使用相同的布局、图标大小、字体层级、间距
- 交互行为统一：统一按钮点击反馈、hover效果、弹窗交互等
  - 所有交互组件的反馈效果完全一致，用户体验统一
- 设计规范落地：形成可复用的UI组件使用规范，后续新增功能遵循该规范
  - 输出明确的组件使用指南，所有新增页面均符合规范要求

# 技术方案
## 技术架构
- 前端：React 19 + Tailwind CSS + shadcn/ui 组件库
- 样式规范：基于现有 `tailwind-theme.css` 全局变量扩展统一组件样式
- 无需后端改动，仅前端样式层面优化

## 统一设计规范（强制遵循）
### 1. 基础规范
- 页面全局内边距：统一使用 `p-6`，保持页面边距一致
- 页面标题：统一使用 `text-2xl font-bold` 作为一级标题
- 次级标题：统一使用 `text-lg font-semibold` 作为区块标题
- 全局圆角：统一使用 `radius-sm = 2px`（基于主题配置），禁用自定义圆角
- 图标尺寸：按钮内图标统一 `size-4`，指标卡图标统一 `size-5`，标题旁图标统一 `size-5`
- 组件间距：按钮组统一 `gap-2`，表单元素统一 `gap-3`，页面区块统一 `space-y-6`

### 2. 指标卡统一规范（所有页面统计卡必须遵循）
- 统一使用 shadcn `<Card>` 组件作为容器
- 布局：`flex items-center gap-3 p-4`
- 图标容器：`size-10 rounded-lg bg-primary/10 text-primary flex items-center justify-center`
- 文本层级：
  - 标签：`text-sm text-muted-foreground`
  - 数值：`text-2xl font-semibold text-foreground`
- 禁止使用自定义div实现指标卡

### 3. 按钮统一规范
- 主按钮高度统一 `h-10`，小按钮统一 `h-8`
- 按钮内边距统一：默认 `px-4`，小按钮 `px-3`
- 图标与文本间距统一 `mr-2`
- hover效果统一使用全局 `hover-elevate` 类，禁止自定义hover背景

### 4. 卡片统一规范
- 所有容器类卡片统一使用 shadcn `<Card>` 组件
- 卡片内边距：默认 `p-4`，头部 `pb-2`
- 卡片边框统一使用 `border border-border`，禁止自定义边框样式

### 5. 表单统一规范
- 输入框高度统一 `h-10`
- 标签统一 `text-xs text-muted-foreground mb-1.5`
- 表单提交按钮统一放在弹窗右下角，按钮顺序：取消在左，确认在右

### 6. 表格统一规范
- 表头高度统一 `h-12`，行高统一 `h-10`
- 表格操作按钮统一使用 `variant="ghost" size="sm"`
- 表格间距统一 `gap-1`
